## Overleaf Quick Start

1. Go to [Overleaf](https://www.overleaf.com/).
2. Click **New Project** → **Upload Project**.
3. Upload the `Research_Paper_Overleaf.zip` archive.
4. Set the compiler to **pdfLaTeX** (Menu → Compiler → pdfLaTeX).
5. Click **Recompile**. The complete 10-page academic research paper will compile cleanly with all figures, equations, tables, and citations.
